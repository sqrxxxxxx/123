# Z_Mems 1.0.0 — Paper 1.21.11

Самостоятельный плагин для Paper 1.21.11 и Java 21. Он не заменяет Z_Test, Z_Lor или Z_Verity и не требует клиентских модов. Для моделей и звуков нужен общий `Z_Server_Pack_1.18.zip`, основанный на версии 1.17. Все прежние ресурсы, кроме описания пака, сохранены побайтно.

## Установка

1. Остановите сервер и положите `Z_Mems-1.0.0.jar` в `plugins`. Существующие JAR и данные других плагинов сохраняйте.
2. Обновите серверный ресурспак до `Z_Server_Pack_1.18.zip`. Если пак раздаётся через `server.properties`, замените ссылку и `resource-pack-sha1` на значения из поставки; если его раздаёт другой плагин — обновите ссылку и хеш там.
3. Запустите сервер, примите предложенный ресурспак и выполните `/zmems menu` с правами оператора. Нажатие на значок в меню выдаёт соответствующий предмет.

## Использование

* `/zmems menu` — меню из 13 сцен и 10 типов смайлов.
* `/zmems list` — ID сцен и смайлов.
* `/zmems give <ник|@s> <id> [количество]` — выдать предмет игроку онлайн.
* `/zmems run <id>` — запустить сцену без предмета.
* `/zmems stop` — остановить временные сцены и мяуканье.

Предмет сцены запускает её по ПКМ, не расходуется и имеет общий настраиваемый перерыв. Смайл ставится ПКМ по блоку; ПКМ смайлом по другому смайлу ставит его сверху. Поставленные смайлы сохраняются после перезапуска. Чтобы забрать свой смайл, нажмите по нему Shift + ПКМ с пустой основной рукой; оператор может забрать любой. В Creative возврат предмета не выдаётся, поскольку он не был израсходован.

Примеры: `/zmems give @s orb_rainbow`, `/zmems give @s pig_dance`, `/zmems run orbital`. Разрешение `zmems.admin` по умолчанию у операторов; выданные предметы используют игроки с `zmems.use` (по умолчанию все).

## Что сделано по роликам

Перечень 13 сцен и сопоставление с каждым файлом — [REVIEW_RU.md](REVIEW_RU.md). В том числе есть отдельные разноцветные смайлы, танцующая свинья, банан и арбуз, космический кот, рогатая корова, город с кранами, орбитальный луч, танцы и мяуканье на прыжках. В сцене космического кота по нему можно нажать сырой треской или тропической рыбой — появятся сердца.

Модели созданы по кадрам заново: исходные 3D-модели и отдельные дорожки звуков из видео не были предоставлены. Поэтому сцены являются воспроизведением идей и наиболее заметных действий, а не покадровой копией оригинальных роликов. Короткие сигналы созданы отдельно; голоса авторов роликов не встроены.

## Настройки

`plugins/Z_Mems/config.yml`: число одновременных сцен, длительность, громкость, задержка между запусками и лимит смайлов в загруженных чанках. Сцены создают временные отображаемые объекты и сами удаляют их при завершении, остановке или выключении плагина. Блоки мира не заменяются декорациями.

Орбитальный удар по умолчанию визуальный. Чтобы включить повреждение существ, измените `scenes.orbital-damage`. Чтобы включить обычный игровой взрыв с изменением блоков, выставьте `scenes.orbital-break-blocks: true`; мощность ограничивается настройкой `scenes.orbital-explosion-power` (до 4). Изменения настроек требуют перезапуска сервера.
